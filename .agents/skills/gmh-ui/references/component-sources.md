# Component sources

Consult these sources only when the project has no suitable existing component or installed library for a required UI part:

- [Kumo by Cloudflare](https://github.com/cloudflare/kumo)
- [Beautiful UI](https://beautifului.dev/)
- [beUI](https://beui.dev/)
- [Rare UI](https://rareui.com/)
- [Transitions](https://transitions.dev/)
- [shadcn/ui](https://ui.shadcn.com/)

Choose a component that fits the project's stack, required behavior, accessibility, and visual rules. Check existing dependencies before adding a library. A source in this list is an option, not a requirement to install it.
